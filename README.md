# AI-Powered Lead Management CRM | n8n Automation

### Overview

An automated lead management system designed to streamline lead intake, data validation, classification, duplicate detection, and email notifications.

Built with **n8n, Webhooks, Google Sheets, Gmail, and API integrations**, this project demonstrates practical business process automation and error-handling workflows.

### Business Problem

Manual lead management can result in duplicate records, inconsistent data, delayed follow-ups, and missed business opportunities.

This solution automates repetitive tasks and improves the consistency of lead processing.

### Key Features

- **Automated Lead Intake:** Receives lead information through API webhooks.
- **Data Validation:** Checks required fields and email formats.
- **Data Normalization:** Standardizes email addresses and lead classifications.
- **Duplicate Detection:** Checks existing records before inserting new leads.
- **Lead Classification:** Routes leads based on their priority.
- **Google Sheets Integration:** Stores new leads and updates notification statuses.
- **Gmail Notifications:** Sends alerts for high-priority leads.
- **Error Handling:** Records notification failures for recovery workflows.

### Technologies

- n8n — Workflow automation
- REST APIs and Webhooks — Data integration
- Google Sheets — Lead storage and tracking
- Gmail — Automated notifications
- Postman — API testing
- JSON — Structured data exchange

### Verified Results

The workflow has been tested with new and existing leads, including email normalization, duplicate prevention, automatic lead registration, and successful notification status updates.
